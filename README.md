# former

Fill and sign a flat PDF in your browser, or turn a scan of a printed form into one people can
actually type into. Nothing is uploaded.

Live at **[former.noradz.io](https://former.noradz.io)**.

## What it's for

Most forms that arrive by email are flat — a scan, or an export with no real form fields in it.
The usual options are buying Adobe, or printing the thing, signing it and scanning it back. This
does it in a tab instead.

It also solves the other half of that problem: make the placements once and export the form
**still blank but now fillable**, with real AcroForm fields lined up over the printed boxes.
Anyone you send it to can click into it in Acrobat or Preview. Making the template is a one-off
job; after that the form fills itself for everyone who receives it.

## Output modes

Place your text, ticks and signature once, then export whichever way you need:

| Mode | What comes out |
| --- | --- |
| **Filled** | The additions burnt into the page. No viewer can un-fill them and no field data rides along in the file. This is the one to send back. |
| **Layered** | Real form fields carrying their values, so whoever receives it can edit them. |
| **Template** | The same fields, empty, with the tab order sorted. A blank form that anyone can fill in. |

There's also a small **JSON sidecar** — your placements plus a fingerprint of the source PDF —
that you can save and load back later. It's for the form you fill in every month: load the
sidecar against the same document and everything is where you left it.

## Privacy

Your document never leaves your browser.

- No upload, no server, no account. The page makes **no network requests at all** once loaded —
  enforced by a Content-Security-Policy you can read in the page source or watch in the Network
  tab.
- No analytics, no error reporting, no telemetry.
- Nothing is stored except your saved signature, which is kept in this browser so you don't have
  to draw it again, and which you can clear in one click at any time. The document, the values
  you type and your placements are held in memory only and are gone when you close the tab.
- Password-protected PDFs are refused rather than silently unlocked.

## Using it

1. Open a PDF. If it already has form fields, you'll be offered the chance to import them.
2. Drag out a box on the page and pick what it is: text, tick, signature, dropdown or radio
   group.
3. Name your fields if you're exporting a template or a layered PDF — two placements sharing a
   name become one field, so "your name" on pages 1, 3 and 7 fills once.
4. Draw or upload a signature. PNG is best; a JPEG has no transparency and carries a white box
   with it.
5. Export.

The editor works from the keyboard as well as the mouse: Tab moves between placements in tab
order, the arrow keys nudge by a point (ten with Shift), Enter opens the properties panel.

## Development

```sh
npm install
npm run dev      # dev server
npm test         # vitest
npm run lint     # oxlint
npm run build    # production build into dist/
```

Vite, Vitest and vanilla JavaScript — no framework. [pdf.js](https://mozilla.github.io/pdf.js/)
renders the pages you drag things onto; [pdf-lib](https://pdf-lib.js.org/) writes the output.
Dependencies are pinned to exact versions and bundled at build time, never loaded from a CDN.

Test fixtures are synthetic and generated by `test/fixtures/generate.js`. Never commit a real
form or a real signature.
